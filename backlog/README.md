# Backlog

Features to implement in `@artstesh/it-should`. One Markdown file per feature.

## Format

- File name: `NNN-short-name.md` with a sequential three-digit number (`001-method-verifier.md`).
- Copy `_template.md` as a starting point.
- Keep the `Status` line up to date: `proposed` → `in-progress` → `done`.
- On release, files with `Status: done` may be removed.

## Rules

- Written in English.
- When a backlog item is taken into work, set `Status: in-progress` and link the branch/PR.
- A feature is only moved to `done` when it is merged, covered by specs, and reflected in the
  documentation (`../should-faq/`).
